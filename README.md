# موسوعة الطاقة الداخلية للمادة

موسوعة عربية علمية تضم **60 فصلًا مستقلًا** موزعة على **12 عائلة معرفية**، وتقدم مسارًا منظمًا لدراسة المساهمات المجهرية والذرية والجزيئية والكيميائية والبنيوية والكهربائية والمغناطيسية في الطاقة الداخلية للمواد، وصولًا إلى القياس والنمذجة والتطبيقات.

## ابدأ من هنا
- [الفهرس الرئيسي للموسوعة](index.html)
- [صفحات العائلات الاثنتي عشرة](families/)
- [الفصول الستون](chapters/)

## بنية المشروع
- `index.html`: بوابة الموسوعة والفهرس العام وروابط الفصول وصفحات العائلات.
- `families/`: 12 صفحة تعريفية ونطاقات موضوعية للعائلات.
- `chapters/`: 60 فصل HTML مستقلًا.
- `assets/style.css`: التنسيق المشترك للصفحات.

## المنهج العلمي
- التمييز بين الطاقة الداخلية والحرارة بوصفها انتقالًا للطاقة.
- التمييز بين الطاقة الداخلية والإنثالبي والطاقة الحرة، وعدم معاملتها كمترادفات.
- بيان الفرضيات وحدود النماذج والمعادلات وشروط استخدامها.
- استخدام وحدات النظام الدولي وتوضيح الرموز.
- التفريق بين الوصف الكلاسيكي والكمومي والإحصائي عند الحاجة.
- عدم تقديم القيم التقريبية بوصفها ثوابت عامة، وتجنب العد المزدوج لمساهمات الطاقة.

## حالة المشروع
اكتملت البنية الأساسية للموسوعة: 60 فصلًا و12 صفحة عائلة وفهرس رئيسي وملف تنسيق مشترك. المحتوى مرجع تعليمي منظم، ولا يغني عن التحقق من المراجع والبيانات التجريبية المتخصصة عند الاستخدام الأكاديمي أو الهندسي.

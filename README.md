# موسوعة الطاقة الداخلية للمادة

موسوعة عربية علمية مفتوحة البنية تضم 60 فصلًا مستقلًا موزعة على 12 عائلة معرفية. يركز المشروع على التحليل الفيزيائي للطاقة المجهرية ومساهماتها في الطاقة الداخلية للمواد.

## بنية المشروع
- `index.html`: بوابة الموسوعة وفهرس العائلات والفصول.
- `families/`: صفحات تعريفية للعائلات العلمية الاثنتي عشرة.
- `chapters/`: ملفات HTML مستقلة للفصول الستين.
- `assets/`: الأنماط والموارد المشتركة.

## المنهج العلمي
- التمييز بين الطاقة الداخلية والحرارة بوصفها انتقالًا للطاقة.
- بيان الفرضيات وحدود النماذج والمعادلات.
- استخدام النظام الدولي للوحدات، مع توضيح الرموز.
- التفريق بين الوصف الكلاسيكي والكمومي والإحصائي عند الحاجة.
- عدم تقديم القيم التقريبية بوصفها ثوابت عامة.

## الحالة
يُبنى المحتوى على دفعات، وتُراجع الروابط والبنية بعد كل دفعة. لا يعني وجود عنوان فصل في الفهرس أن نصه العلمي قد اكتمل بعد.
